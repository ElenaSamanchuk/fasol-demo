# Фасоль — демо сайта ресторана

Демо для ООО «Орион Холл»: витрина меню как в Яндекс Еде, заказ с собой с имитацией статусов, бронь стола, фирменный стиль «Фасоли».
Цены, вес и КБЖУ — примеры; заказы и брони никуда не отправляются. Страница закрыта от индексации (noindex).

Стек: React + Vite + Tailwind CSS 4, анимации — motion, шторки — vaul.

```bash
npm i
npm run dev     # локально
npm run build   # сборка в dist/ для GitHub Pages
```
